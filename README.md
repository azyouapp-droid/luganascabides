# Luganas Cabides

Vitrine responsiva em HTML, CSS e JavaScript, sem dependências de produção.

## Páginas

- `index.html`: início, destaques, banners e dúvidas frequentes.
- `cabides.html`: coleção de cabides.
- `bustos.html`: coleção de bustos.
- `manequins.html`: linhas de manequins e filtros.

Abra `index.html` no navegador ou publique a raiz deste repositório em uma hospedagem estática. Todos os arquivos HTML precisam ficar junto de `styles.css`, `script.js` e da pasta `assets`.

Para prévia local com Node.js, execute `npm start` e acesse http://127.0.0.1:4173.

Os links de contato disponíveis levam ao Instagram @luganascabides. As informações de contato ainda não fornecidas permanecem como rótulos sem link. As imagens incluem conceitos gerados e referências fornecidas pelo cliente.

As páginas compartilham estilos responsivos, transições, animações de texto e navegação por teclado. Os efeitos respeitam a preferência de movimento reduzido.
